## Cross-repository relationships

- `Jasoneagle/offline-ai-media-asset-pipeline` owns reusable offline media/asset-pipeline architecture and private/local production boundaries; this public repository contains only suitable public fictional-character output/project records.
- `Jasoneagle/forum-games` or `Jasoneagle/game-modding` remains the canonical owner when an image is produced for one of those projects; do not move story, character, or game canon here merely because an image output is stored here.
- `Jasoneagle/conversation-archive` owns historical conversation evidence and handoffs. Do not expose private archive provenance, subject material, or private-media paths in this public repository.

The audited complete recursive tree contains no project-local handoff/checkpoint subtree. Historical generation continuity therefore remains with the private archive or the actual owning project unless a future tree adds a suitable public continuity record.

## Working rule

Character images must be grounded in the requested written source. Unspecified features should remain neutral rather than borrowing from screen adaptations. Generated images rejected by the user are not canonical assets. Cross-reference an owning project instead of duplicating its complete canon.
